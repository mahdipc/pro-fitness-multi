# Expected Output Contract

The system must produce exactly two Persian Markdown files.

## File 1: WorkoutPlan.fa.md

Must include:

- summary of user situation
- goal
- weekly schedule
- each workout day
- warm-up
- exercises with sets/reps/rest/RPE/alternative
- cardio if appropriate
- cooldown
- progression rules
- nutrition and recovery notes
- safety notes

## File 2: DecisionReport.fa.md

Must include:

- extracted profile
- missing information
- assumptions
- safety and risk analysis
- conflicts between opposing agents
- final arbitration decisions
- reasons for weekly structure
- reasons for exercise selection
- progression logic
- what would change if missing data is provided
- final validation summary

## Forbidden

- No guaranteed result claims.
- No medical diagnosis.
- No hidden chain-of-thought.
- No exercises outside approved library.
- No plan without alternatives.
