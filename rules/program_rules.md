# Program Rules

## Default Training Level Rules

If level is unknown:

- assume beginner-to-intermediate;
- use moderate volume;
- choose simple exercises;
- include alternatives;
- keep intensity mostly RPE 6-8.

## Weekly Frequency Defaults

- Beginner: 2-3 resistance sessions/week.
- Intermediate: 3-4 resistance sessions/week.
- Advanced: 4-6 resistance sessions/week only if recovery, experience, and schedule support it.

## Session Structure

Each session must include:

1. Warm-up
2. Main workout
3. Optional cardio or finisher if appropriate
4. Cooldown
5. Safety notes or technique reminders

## Exercise Programming Requirements

Every exercise must include:

- exercise name
- target muscles
- sets
- reps or duration
- rest seconds
- intensity guidance, such as RPE or RIR
- alternative exercise

## Volume Guardrails

If recovery is unclear or poor:

- use lower volume;
- start with 2-3 sets per exercise;
- avoid too many exercises per session;
- avoid training the same muscle hard on consecutive days.

## Time Constraint Rule

If user has limited session time, reduce exercises before reducing warm-up and safety content.

## Deload Rule

For plans longer than 4 weeks, include at least one deload or lighter week option if fatigue rises.
